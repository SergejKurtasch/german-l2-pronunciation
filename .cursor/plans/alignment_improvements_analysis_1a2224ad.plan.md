# Анализ результатов выравнивания и рекомендации по улучшению

## Текущая ситуация

На основе анализа 1000 записей из ноутбука `deep_phoneme_mismatch_analysis.ipynb`:

- **Общий PER**: 0.26 (26% ошибок)
- **Всего несоответствий**: 10,203 (7,600 подстановок, 1,858 удалений, 745 вставок)
- **Среднее PER для заимствований**: 0.27 (выше, чем для обычных слов: 0.26)

## Выявленные проблемы

### 1. Проблемы с составными словами и именами

**Примеры из данных:**

- `"Lawrence kansas"` - PER 0.64, много ошибок: `a→ɔ, -v, ʁ→ɹ, ɛ→ə, ŋ→n`
- `"Plug-in-Hybrid"` - PER 0.38, 26 ошибок
- `"Annemarie"` - составное имя, ошибки: `a→ɑː, yː→y, ʁ→ɾ`
- `"Süderbrarup"` - название места, PER 0.32
- `"Happy Purzeltag"` - смешанный язык, PER 0.65

**Проблема**: Составные слова и имена часто имеют более высокий PER из-за:

- Разной длины фонемных последовательностей между expected и recognized
- Особенностей произношения заимствований (английские звуки в немецком контексте)
- Недостаточной обработки в алгоритме выравнивания для длинных составных слов
- Различий в произношении между частями составного слова

### 2. Частые ошибки выравнивания

**Топ-10 подстановок:**

1. `ɐ → ɾ` (732 случая) - центральный гласный → альвеолярный тап
2. `s → ts` (414) - фрикатив → аффриката
3. `eː → ɛ` (360) - долгий гласный → краткий
4. `ɐ → ɜ` (297) - центральные гласные
5. `ʁ → ɾ` (281) - увулярный R → альвеолярный тап

**Топ удалений:**

- `t` (389), `a` (349), `ə` (158), `ɛ` (145)

**Топ вставок:**

- `ə` (183), `ɾ` (75), `t` (70)

## Рекомендации по улучшению

### Приоритет 1: Обработка составных слов и имён

#### 1.1 Определение составных слов

**Файлы для изменения:**

- `modules/g2p_module.py` - добавление логики определения составных слов
- `modules/word_boundary_utils.py` (если существует) или создание нового модуля

**Подход:**

1. **Распознавание составных слов по паттернам:**

        - Слова с дефисами: `Plug-in-Hybrid`, `Hotel-`
        - Немецкие составные слова без пробелов: `Sonnenuntergang`, `Lebensdauer`
        - Имена собственные: `Annemarie`, `Süderbrarup`, `Karsten`

2. **Словарь исключений для имён:**

        - Создать список известных имён и топонимов
        - Использовать специальные правила транскрипции для имён

3. **Правила для составных слов:**

        - Для слов с дефисами: обрабатывать как единое целое при выравнивании
        - Для немецких составных: учитывать структуру слова при выравнивании
        - Использовать более мягкие штрафы за пропуски в составных словах

#### 1.2 Специальная обработка при выравнивании

**Изменения в `modules/alignment.py`:**

Добавить функцию для определения типа слова и применения соответствующих правил:

```python
def get_word_type(word: str) -> str:
    """
    Определяет тип слова для применения специальных правил выравнивания.
    
    Returns:
        'compound': составное слово
        'proper_noun': имя собственное
        'loanword': заимствование
        'regular': обычное слово
    """
    if '-' in word:
        return 'compound'
    if word in PROPER_NOUNS_DICT:
        return 'proper_noun'
    if word in LOANWORDS_DICT:
        return 'loanword'
    return 'regular'
```

### Приоритет 2: Оптимизация параметров выравнивания

#### 2.1 Настройка штрафов за пропуски

**Файл:** `config.py`

**Текущие параметры:**

```python
NW_GAP_PENALTY = -1.0
```

**Рекомендации:**

1. **Дифференцированные штрафы:**

        - Меньший штраф для пропусков в конце слов: `-0.5`
        - Стандартный штраф для середины: `-1.0`
        - Больший штраф для пропусков в начале: `-1.5`

2. **Контекстные штрафы:**

        - Меньший штраф для пропусков `ə` (schwa) в безударных позициях
        - Меньший штраф для пропусков согласных в кластерах

#### 2.2 Улучшение матрицы схожести фонем

**Файл:** `modules/phoneme_similarity.py`

**Текущие веса:**

```python
FEATURE_WEIGHT_VOICING = 0.25
FEATURE_WEIGHT_PLACE = 0.35
FEATURE_WEIGHT_MANNER = 0.30
```

**Рекомендации:**

1. **Увеличить вес для места артикуляции** (важно для R-звуков):
   ```python
   FEATURE_WEIGHT_PLACE = 0.40  # было 0.35
   ```

2. **Добавить специальные правила для частых путаниц:**

        - `ɐ → ɾ`: увеличить схожесть (оба центральные/альвеолярные)
        - `s → ts`: уменьшить схожесть (аффриката vs фрикатив)
        - `eː → ɛ`: увеличить схожесть (тот же гласный, разная долгота)

### Приоритет 3: Постобработка выравнивания

#### 3.1 Сглаживание выравнивания для составных слов

**Новый модуль:** `modules/alignment_postprocessing.py`

**Функции:**

1. **Объединение соседних пропусков:**

        - Если несколько пропусков подряд в одной последовательности, возможно, это артефакт выравнивания

2. **Коррекция выравнивания для составных слов:**

        - Проверка на артефакты выравнивания в длинных словах
        - Сглаживание выравнивания для составных слов

3. **Валидация выравнивания:**

        - Проверка на нереалистичные паттерны (например, слишком много пропусков подряд)

#### 3.2 Обработка частых паттернов ошибок

**Создать правила коррекции для:**

- `s → ts` в конце слов (часто артефакт распознавания)
- Пропуски `ə` в безударных слогах
- Пропуски `t` перед `s` (кластер `ts`)

### Приоритет 4: Улучшение обработки заимствований
