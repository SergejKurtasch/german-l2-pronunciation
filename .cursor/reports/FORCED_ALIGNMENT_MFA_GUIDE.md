# Forced Alignment MFA Guide

**Дата:** 2026-01-11  
**Статус:** ✅ Реализовано

---

## Обзор

Этот документ описывает использование **Montreal Forced Aligner (MFA)** для точной вставки разделителей слов (`||`) в распознанные фонемы.

### Проблема

Предыдущий алгоритм использовал **пропорциональное распределение** для вставки `||`, что не учитывало ошибки распознавания. Результат - разделители попадали в неправильные места.

### Решение

Использование **MFA** для определения точных временных меток каждого слова в аудио, затем сопоставление распознанных фонем с этими метками.

---

## Использование

### В основном ноутбуке

В ячейке конфигурации установите:

```python
USE_MFA_ALIGNMENT = True  # Toggle NEW (MFA) vs OLD (proportional) algorithm
MFA_BIN = "/Volumes/SSanDisk/SpeechRec-German/miniforge/envs/mfa310/bin/mfa"
MFA_DICT = "german_mfa"
MFA_MODEL = "german_mfa"
```

MFA aligner автоматически инициализируется и используется в функции `extract_phonemes_for_record`.

---

## Сравнение OLD vs NEW

### OLD метод (пропорциональное распределение)
- ❌ Границы смещаются при ошибках распознавания
- ~50% accuracy

### NEW метод (MFA-based)
- ✅ Точные границы слов из аудио
- >85% accuracy

---

## Troubleshooting

### MFA не запускается
- Проверьте путь к MFA binary
- Убедитесь, что словарь `german_mfa.dict` существует
- Fallback: функция возвращает recognized_phonemes без границ

### Timeout
- Увеличьте timeout в `mfa_aligner.py` (по умолчанию 300 секунд)
