# Анализ проблемы: Отсутствие символа ʔ (glottal stop) в результатах распознавания

## Дата анализа
11 января 2026

## Проблема
Модель HuggingFace `facebook/wav2vec2-xlsr-53-espeak-cv-ft` не возвращает символ ʔ (glottal stop, гортанная смычка) в результатах распознавания, хотя:
1. Символ ʔ присутствует в словаре модели (ID: 80)
2. Символ ʔ должен появляться в немецких словах (например, "aber" → ʔɑːbeɾ)
3. В результатах из примеров с идеальным произношением ʔ отсутствует

## Проведенные тесты

### ТЕСТ 1: Phoneme Normalizer ✅ ПРОШЕЛ
```

Нормализация (source='dictionary'): ['ʔ', 'ɑː', 'b', 'e', 'ɾ', 'ʔ', 'ʊ', 'n', 'z']
Нормализация (source='model'): ['ʔ', 'ɑː', 'b', 'e', 'ɾ', 'ʔ', 'ʊ', 'n', 'z']
```

**Результат:** Символ ʔ НЕ удаляется нормализатором фонем.

**Проверки:**
- ʔ в `chars_to_remove`: **False**
- ʔ в `diacritics_to_remove`: **False**
- ʔ в `suprasegmentals_to_remove`: **False**
- ʔ в `model_inventory`: **True**

### ТЕСТ 3: Decode Phonemes Logic ✅ ПРОШЕЛ

Токены после CTC collapse: ['ʔ', 'ɑː', 'b', 'e', 'ʔ']
После фильтрации skip_tokens: ['ʔ', 'ɑː', 'b', 'e', 'ʔ']
'ʔ' в skip_tokens: False
```

**Результат:** Символ ʔ НЕ удаляется в процессе декодирования.

### ТЕСТ 2: G2P Normalization ⚠️ НЕ ЗАВЕРШЕН
Тест не завершился из-за проблем с доступом к debug.log в sandbox.

### 2. МОДЕЛЬ НЕ ВОЗВРАЩАЕТ ʔ В ПРЕДСКАЗАНИЯХ ❌
Наиболее вероятная причина: **модель просто не распознает ʔ в своих предсказаниях (argmax)**.

## Возможные причины отсутствия ʔ в предсказаниях модели

### Гипотеза 1: Модель обучена без примеров с ʔ
Модель `facebook/wav2vec2-xlsr-53-espeak-cv-ft` могла быть обучена на данных, где:
- Glottal stop не был явно размечен в аннотациях
- eSpeak-NG не генерировал ʔ для немецких слов
- Аннотаторы не отмечали гортанную смычку

### Гипотеза 2: ʔ встречается слишком редко
В датасете Common Voice и других обучающих данных:
- Символ ʔ может быть очень редким (< 0.1% от всех фонем)
- Модель не научилась его распознавать из-за дисбаланса классов
- Argmax всегда выбирает более частые фонемы

### Гипотеза 3: Акустическая неразличимость
Гортанная смычка:
- Очень короткая (обычно < 50ms)
- Может быть неразличима от паузы
- Не всегда четко выражена в спонтанной речи
- В немецком языке часто опускается говорящими

#### 1. Вставка ʔ на основе правил (Rule-based insertion)
Для немецкого языка можно автоматически вставлять ʔ:
- В начале слов, начинающихся с гласной

- Перед ударными гласными

            # Вставить ʔ перед первой фонемой слова
            ...
    
    # Правило 2: В сложных словах (Komposita)
    # Вставить ʔ на границах морфем
    ...
```

**Плюсы:**
- Быстро реализуется
- Улучшает точность для немецкого языка
- Не требует переобучения модели

**Минусы:**
- Не работает для других языков
- Могут быть ложные срабатывания
- Не учитывает фактическое произношение

#### 2. Post-processing на основе G2P
Использовать ожидаемые фонемы из G2P:
```python

recognized_phonemes = model.recognize(audio)      # Без ʔ

```

**Плюсы:**
- Использует лингвистические знания
- Улучшает согласованность с ожидаемыми фонемами

**Минусы:**
- Зависит от качества G2P
- Не помогает, если пользователь НЕ произносит ʔ

### Долгосрочные решения

#### 1. Fine-tuning модели
Fine-tune модель на датасете с явной разметкой ʔ:
- Использовать Force Alignment для создания точной разметки
- Увеличить вес класса ʔ при обучении (class weighting)
- Использовать focal loss для редких классов

#### 2. Использование другой модели
Попробовать модели, обученные специально на немецком:
- Models from torchaudio (German-specific)
- Custom German phoneme recognition models

#### 3. Ensemble подход
Комбинировать несколько источников:
1. Acoustic model (Wav2Vec2) - для большинства фонем
2. Rule-based system - для ʔ
3. G2P - для валидации
