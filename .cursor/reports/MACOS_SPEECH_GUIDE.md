# Использование macOS Speech Framework вместо Whisper

## Обзор

Проект теперь поддерживает два движка распознавания речи:
1. **Whisper** (по умолчанию) - кроссплатформенный, требует загрузки модели
2. **macOS Speech** - нативный движок macOS, быстрее, но работает только на macOS

## Преимущества macOS Speech

1. **Скорость**: Не требует загрузки модели, работает мгновенно
2. **Производительность**: Использует оптимизированный нативный код и Neural Engine на Apple Silicon
3. **Размер**: Не занимает место на диске (модели уже в системе)
4. **Интеграция**: Лучше интегрирован с системой macOS

## Недостатки macOS Speech

1. **Только macOS**: Работает только на macOS
2. **Ограниченные языки**: Зависит от языков, установленных в системе
3. **Требует разрешений**: Нужно разрешить доступ к микрофону/распознаванию речи

## Настройка

### 1. Установка зависимостей

```bash
pip install pyobjc-framework-Speech
```

Или установите все зависимости:
```bash
pip install -r requirements.txt
```

### 2. Настройка языка в системе

1. Откройте **Системные настройки** > **Клавиатура** > **Диктовка**
2. Убедитесь, что диктовка включена
3. Установите нужные языки (например, немецкий)

### 3. Настройка в config.py

Откройте `config.py` и измените:

```python
ASR_ENGINE = "macos"  # Использовать macOS Speech вместо Whisper
ASR_LANGUAGE = "de"   # Будет автоматически преобразован в "de-DE" для macOS
```

Или для английского:
```python
ASR_ENGINE = "macos"
ASR_LANGUAGE = "en"   # Будет преобразован в "en-US"
```

## Коды языков

macOS Speech использует коды BCP-47:
- Немецкий: `de-DE` (автоматически из `de`)
- Английский (US): `en-US` (автоматически из `en`)
- Английский (UK): `en-GB`
- Французский: `fr-FR`
- Испанский: `es-ES`

Если указан короткий код (например, `de`), он автоматически преобразуется в полный код (`de-DE`).

## Автоматическое определение языка

macOS Speech может автоматически определять язык, но для лучшей точности рекомендуется указывать язык явно.

## Сравнение производительности

### Whisper (medium модель)
- **Время загрузки**: ~2-5 секунд (при первом запуске)
- **Время распознавания**: ~6-7 секунд для аудио длительностью 5-10 секунд
- **Использование памяти**: ~1-2 GB
- **Размер модели**: ~769 MB (medium)

### macOS Speech
- **Время загрузки**: Мгновенно (не требуется загрузка модели)
- **Время распознавания**: ~1-2 секунды для аудио длительностью 5-10 секунд
- **Использование памяти**: Минимальное
- **Размер модели**: 0 MB (использует системные модели)

**Ожидаемое ускорение**: 3-5x быстрее, чем Whisper

## Переключение между движками

Вы можете переключаться между движками, изменив `ASR_ENGINE` в `config.py`:

```python
# Использовать Whisper
ASR_ENGINE = "whisper"

# Использовать macOS Speech (с автоматическим fallback на Whisper)
ASR_ENGINE = "macos"
```

### Автоматическое переключение (Fallback)

**Важно**: Если в `config.py` установлено `ASR_ENGINE = "macos"`, но:
- Вы используете не macOS (Linux, Windows)
- macOS Speech framework не установлен
- Инициализация macOS Speech не удалась

То система **автоматически переключится на Whisper** без ошибок. Вы увидите предупреждение в консоли, но приложение продолжит работать с Whisper.

Это означает, что вы можете установить `ASR_ENGINE = "macos"` в конфигурации, и она будет работать оптимально на macOS, а на других платформах автоматически использовать Whisper.

## Разрешения

При первом использовании macOS Speech система может запросить разрешение на доступ к микрофону. Это нормально и необходимо для работы распознавания речи.

## Устранение неполадок

### Ошибка: "Speech recognition is not available for locale"

**Решение**: 
1. Убедитесь, что язык установлен в системе (Системные настройки > Клавиатура > Диктовка)
2. Проверьте, что диктовка включена
3. Перезапустите приложение

### Ошибка: "Failed to create speech recognizer"

**Решение**:
1. Убедитесь, что установлен `pyobjc-framework-Speech`: `pip install pyobjc-framework-Speech`
2. Проверьте версию macOS (требуется macOS 10.15+)
3. Попробуйте использовать Whisper как альтернативу

### Медленная работа

**Решение**:
- macOS Speech обычно быстрее Whisper
- Если медленно, проверьте, что используется правильный язык
- Убедитесь, что аудио файл в поддерживаемом формате (WAV, M4A, etc.)

## Пример использования

Код автоматически использует выбранный движок:

```python
# В config.py
ASR_ENGINE = "macos"  # или "whisper"

# В app.py - автоматически используется правильный движок
asr_recognizer = get_speech_recognizer(engine=config.ASR_ENGINE)
text = asr_recognizer.transcribe(audio_path, language="de")
```

## Рекомендации

1. **Для macOS**: Используйте `ASR_ENGINE = "macos"` для максимальной скорости
2. **Для других платформ**: Используйте `ASR_ENGINE = "whisper"` (по умолчанию)
3. **Для разработки**: Whisper может быть полезнее для отладки (больше информации)
4. **Для продакшена на macOS**: macOS Speech предпочтительнее из-за скорости
