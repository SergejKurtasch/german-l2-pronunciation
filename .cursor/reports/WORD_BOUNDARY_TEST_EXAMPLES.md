## 🎯 Ключевая особенность

**Функция НЕ схлопывает одинаковые фонемы на границах слов!**

Это критически важно для корректного анализа, так как немецкий язык имеет много случаев, когда одно слово заканчивается той же фонемой, с которой начинается следующее.

---

## 📝 Примеры

### Пример 1: "an Nadine" (n → n)

Слово "an" заканчивается на фонему `n`, слово "Nadine" начинается с фонемы `n`.

```python
text = "an Nadine"

expected_phonemes = ['a', 'n', '||', 'n', 'a', 'd', 'i', 'n', 'ə']
#                     ^слово 1^  ^-------слово 2---------^
#                          ↓ конец "an"
#                             ↓ начало "Nadine"

recognized_phonemes = ['a', 'n', 'n', 'a', 'd', 'i', 'n', 'ə']
#                       ^первое n  ^второе n

# ПОСЛЕ insert_word_boundaries:
result = ['a', 'n', '||', 'n', 'a', 'd', 'i', 'n', 'ə']
#         ^слово 1^  ^-------слово 2---------^

# ✅ ОБА 'n' сохранены!
# ✅ Boundary вставлен между ними
```

**Почему это важно:**
- Если бы мы схлопнули два `n` в один, получили бы только 7 фонем вместо 8
- Alignment был бы некорректным
- Мы бы потеряли информацию о границе слова

---

### Пример 2: "mit Tina" (t → t)

Слово "mit" заканчивается на `t`, слово "Tina" начинается с `t`.

```python
text = "mit Tina"

expected_phonemes = ['m', 'ɪ', 't', '||', 't', 'i', 'n', 'a']
#                    ^слово 1^  ^-----слово 2------^

recognized_phonemes = ['m', 'ɪ', 't', 't', 'i', 'n', 'a']

# ПОСЛЕ insert_word_boundaries:
result = ['m', 'ɪ', 't', '||', 't', 'i', 'n', 'a']

# ✅ ОБА 't' сохранены!
```

---

### Пример 3: "eine Ende" (ə → e, близкие фонемы)

Слово "eine" заканчивается на `ə`, слово "Ende" начинается с `e`.

```python
text = "eine Ende"

expected_phonemes = ['aɪ', 'n', 'ə', '||', 'ɛ', 'n', 'd', 'ə']
#                    ^-слово 1-^  ^-----слово 2------^

recognized_phonemes = ['aɪ', 'n', 'ə', 'e', 'n', 'd', 'ə']
#                                ↑    ↑
#                            конец "eine" (ə)
#                                 начало "Ende" (e, распознано как e вместо ɛ)

# ПОСЛЕ insert_word_boundaries:
result = ['aɪ', 'n', 'ə', '||', 'e', 'n', 'd', 'ə']

# ✅ ОБЕ фонемы сохранены (даже если они разные)
# ✅ Alignment покажет, что ɛ→e (реальная ошибка модели)
```

---

### Пример 4: "das sind" (s → s)

Слово "das" заканчивается на `s`, слово "sind" начинается с `z` (но модель может распознать как `s`).

```python
text = "das sind"

expected_phonemes = ['d', 'a', 's', '||', 'z', 'ɪ', 'n', 't']
#                    ^слово 1^  ^-----слово 2------^

recognized_phonemes = ['d', 'a', 's', 's', 'ɪ', 'n', 't']
#                                ↑    ↑
#                            конец "das" (s)
#                                 начало "sind" (z → s ошибка!)

# ПОСЛЕ insert_word_boundaries:
result = ['d', 'a', 's', '||', 's', 'ɪ', 'n', 't']

# ✅ ОБА 's' сохранены
# ✅ Alignment покажет, что z→s (реальная ошибка модели)
```

## 🔧 Алгоритм работы

### Шаг 1: Разбить текст на слова
```python
words = text.split()  # ['an', 'Nadine']
```

### Шаг 2: Разбить expected phonemes по `||`
```python
expected_word_groups = [
    ['a', 'n'],           # слово 1: "an"
    ['n', 'a', 'd', 'i', 'n', 'ə']  # слово 2: "Nadine"
]
```

### Шаг 3: Вычислить ожидаемое количество фонем на слово
```python
expected_counts = [2, 6]  # "an": 2 фонемы, "Nadine": 6 фонем
total_expected = 8
```

### Шаг 4: Пропорционально распределить recognized phonemes
```python
recognized_phonemes = ['a', 'n', 'n', 'a', 'd', 'i', 'n', 'ə']  # 8 фонем
recognized_count = 8

# Слово 1: пропорция = 2/8 = 0.25 → 0.25 * 8 = 2 фонемы
word1_phonemes = ['a', 'n']  # индексы [0:2]

# Слово 2: оставшиеся фонемы
word2_phonemes = ['n', 'a', 'd', 'i', 'n', 'ə']  # индексы [2:8]
```

### Шаг 5: Вставить `||` между группами
```python
result = word1_phonemes + ['||'] + word2_phonemes
# ['a', 'n', '||', 'n', 'a', 'd', 'i', 'n', 'ə']
```

**Ключевой момент:** Мы **НЕ сравниваем** фонемы на границах. Мы просто вставляем `||` между группами, сохраняя все фонемы.

## ❌ Как НЕ надо делать

### Неправильный подход 1: Схлопывание одинаковых фонем
```python
# ❌ ПЛОХО: Удаляем дубликаты на границах
if word1[-1] == word2[0]:
    # Удалить один из них
    pass

# Проблема:
# - Теряем фонему
# - Alignment некорректен
# - Не можем определить, где граница слова
```

### Неправильный подход 2: Пропорция без учета текста
```python
# ❌ ПЛОХО: Вставляем || просто по пропорции, не зная, где слова
boundary_positions = [3]  # После 3 фонем в expected
ratio = 8 / 8 = 1.0
insert_at = 3 * 1.0 = 3

# Проблема:
# - Если модель пропустила/добавила фонему в первом слове, граница будет неправильной
# - Не учитываем структуру слов
```

## 📊 Преимущества нового алгоритма

| Критерий | Старая версия | Новая версия |
|----------|---------------|--------------|
| **Использует текст** | ❌ Нет | ✅ Да |
| **Сохраняет фонемы на границах** | ⚠️ Может потерять | ✅ Сохраняет |
| **Учитывает структуру слов** | ❌ Только пропорция | ✅ Word-aware |
| **Точность границ** | ⚠️ Зависит от ошибок модели | ✅ Выше |
| **Fallback механизм** | ❌ Нет | ✅ Есть |

## 🧪 Тестовые кейсы

### Кейс 1: Одинаковые фонемы на границе
```python
assert insert_word_boundaries(
    text="an Nadine",
    expected=['a', 'n', '||', 'n', 'a', 'd', 'i', 'n', 'ə'],
    recognized=['a', 'n', 'n', 'a', 'd', 'i', 'n', 'ə']
) == ['a', 'n', '||', 'n', 'a', 'd', 'i', 'n', 'ə']
```

### Кейс 2: Разные длины (модель пропустила фонему)
```python
assert insert_word_boundaries(
    text="mit Tina",
    expected=['m', 'ɪ', 't', '||', 't', 'i', 'n', 'a'],  # 7 фонем
    recognized=['m', 'ɪ', 't', 'i', 'n', 'a']  # 6 фонем (пропущено одно 't')
) == ['m', 'ɪ', 't', '||', 'i', 'n', 'a']
# Пропорционально: слово 1 = 3/7 * 6 ≈ 2.57 → 3 фонемы
#                  слово 2 = оставшиеся 3 фонемы
```

### Кейс 3: Одно слово (без границ)
```python
assert insert_word_boundaries(
    text="Hallo",
    expected=['h', 'a', 'l', 'oː'],
    recognized=['h', 'a', 'l', 'oː']
) == ['h', 'a', 'l', 'oː']  # Без || (одно слово)
```
