# Рекомендации по добавлению пар фонем для вторичной верификации

На основе анализа результатов ноутбука `deep_phoneme_mismatch_analysis.ipynb` (1000 записей, 7814 случаев подстановок).

## Текущая ситуация

В проекте `german-phoneme-validator` уже реализованы 22 пары фонем для вторичной верификации.

## Топ-10 существующих путаниц (из анализа)

1. **ɐ → ɾ**: 762 случая
2. **s → ts**: 472 случая
3. **eː → ɛ**: 379 случаев
4. **ɐ → ɜ**: 310 случаев
5. **ʁ → ɾ**: 308 случаев
6. **ʁ → r**: 265 случаев
7. **ɾ → r**: 261 случай
8. **aː → ɑː**: 231 случай
9. **e → aɪ**: 203 случая
10. **tʰ → t**: 138 случаев

## Рекомендуемые пары для добавления

### Приоритет 1 (высокая частота, >100 случаев)

1. **s → ts** (472 случая)
   - **Тип**: Аффриката vs фрикатив
   - **Важность**: Критически важная пара для немецкого языка
   - **Обоснование**: Очень высокая частота ошибок, аффрикаты часто путаются с фрикативами

2. **e → aɪ** (203 случая)
   - **Тип**: Монофтонг vs дифтонг
   - **Важность**: Высокая
   - **Обоснование**: Частая путаница между кратким гласным и дифтонгом

3. **o → aʊ** (133 случая)
   - **Тип**: Монофтонг vs дифтонг
   - **Важность**: Высокая
   - **Обоснование**: Аналогично предыдущей паре, систематическая ошибка

4. **ɛ → ə** (139 случаев)
   - **Тип**: Гласные среднего ряда
   - **Важность**: Высокая
   - **Обоснование**: Фонетически близкие гласные, частые ошибки

5. **a → ɑː** (111 случаев)
   - **Тип**: Краткий vs долгий гласный
   - **Важность**: Высокая
   - **Обоснование**: Проблема с различием долготы гласных

### Приоритет 2 (средняя частота, 50-100 случаев)

6. **ɐ → ə** (108 случаев)
   - **Тип**: Центральные гласные
   - **Важность**: Средняя
   - **Обоснование**: Путаница между центральными гласными

7. **e → eː** (91 случай)
   - **Тип**: Краткий vs долгий гласный
   - **Важность**: Средняя
   - **Обоснование**: Систематическая проблема с долготой

8. **n̩ → n** (89 случаев)
   - **Тип**: Слоговый согласный vs обычный
   - **Важность**: Средняя
   - **Обоснование**: Специфично для немецкого языка

9. **ɪ → aɪ** (89 случаев)
   - **Тип**: Краткий гласный vs дифтонг
   - **Важность**: Средняя
   - **Обоснование**: Частая путаница с дифтонгами

10. **ɪ → iː** (89 случаев)
    - **Тип**: Краткий vs долгий гласный
    - **Важность**: Средняя
    - **Обоснование**: Проблема с долготой гласных

11. **i → iː** (88 случаев)
    - **Тип**: Краткий vs долгий гласный
    - **Важность**: Средняя
    - **Обоснование**: Аналогично предыдущим парам

12. **aː → a** (88 случаев)
    - **Тип**: Долгий vs краткий гласный
    - **Важность**: Средняя
    - **Обоснование**: Обратная путаница долготы

13. **o → oː** (86 случаев)
    - **Тип**: Краткий vs долгий гласный
    - **Важность**: Средняя
    - **Обоснование**: Систематическая проблема

14. **ʊ → uː** (84 случая)
    - **Тип**: Краткий vs долгий гласный
    - **Важность**: Средняя
    - **Обоснование**: Проблема с долготой задних гласных

15. **ɔ → oː** (76 случаев)
    - **Тип**: Открытый vs закрытый гласный
    - **Важность**: Средняя
    - **Обоснование**: Путаница между открытыми и закрытыми гласными

16. **e → ə** (72 случая)
    - **Тип**: Гласные переднего ряда vs центральный
    - **Важность**: Средняя
    - **Обоснование**: Фонетически близкие звуки

17. **iː → aɪ** (66 случаев)
    - **Тип**: Долгий гласный vs дифтонг
    - **Важность**: Средняя
    - **Обоснование**: Путаница между долгим гласным и дифтонгом

18. **ɾ → ɜ** (65 случаев)
    - **Тип**: Согласный vs гласный
    - **Важность**: Средняя
    - **Обоснование**: Необычная, но частая ошибка

### Приоритет 3 (дополнительные важные пары)

19. **ɛː → ɛ** (120 случаев)
    - **Тип**: Долгий vs краткий гласный
    - **Важность**: Средняя
    - **Обоснование**: Проблема с долготой, высокая частота

20. **ʀ → r** (72 случая)
    - **Тип**: Варианты R-звука
    - **Важность**: Средняя
    - **Обоснование**: Вариативность произношения R в немецком

## Статистика по типам ошибок

### По категориям:

1. **Аффрикаты и фрикативы**: s → ts (472)
2. **Дифтонги**: e → aɪ (203), o → aʊ (133), ɪ → aɪ (89), iː → aɪ (66)
3. **Долгота гласных**: e → eː (91), aː → a (88), o → oː (86), ʊ → uː (84), ɛː → ɛ (120)
4. **Центральные гласные**: ɐ → ə (108), ɛ → ə (139), e → ə (72)
5. **Слоговые согласные**: n̩ → n (89)
6. **Варианты R**: ʀ → r (72)

## Рекомендации по реализации

### Первая очередь (топ-5):
1. s → ts
2. e → aɪ
3. o → aʊ
4. ɛ → ə
5. a → ɑː

### Вторая очередь (топ-10):
6. ɐ → ə
7. e → eː
8. n̩ → n
9. ɪ → aɪ
10. ɛː → ɛ

### Третья очередь (остальные):
11-20. Остальные пары из приоритета 2 и 3

## Ожидаемый эффект

Добавление этих 20 пар должно значительно улучшить точность вторичной верификации, так как они покрывают:
- **~35%** всех случаев подстановок (если считать только топ-10)
- Основные фонетические категории ошибок в немецком языке
- Систематические проблемы с долготой гласных и дифтонгами

## Примечания

- Все частоты основаны на анализе 1000 записей из датасета TV-2021.02-Neutral
- Учитываются только случаи подстановок (substitutions), исключая удаления и вставки
- Рекомендуется начать с пар приоритета 1, затем постепенно добавлять остальные
- При добавлении новых пар важно проверить их влияние на общую точность валидации
